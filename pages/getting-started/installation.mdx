## 0.1: Installation

- **Time to Complete:** 15 minutes

> Prefer the terminal? → [Claude Code CLI guide](/getting-started/claude-code-cli)

## Prerequisites

- **Claude Pro or Max subscription** (NOT free tier)
  - Sign up at [claude.ai](https://claude.ai) if you don't have one
  - $20/month for Pro
- Mac (macOS 10.15+) or Windows 10+
- 4 GB+ RAM
- Internet connection
- **No coding tools required!**

**On Linux?** There's no desktop app yet - use the [Claude Code CLI guide](/getting-started/claude-code-cli) instead. Everything in the course works there too.

## Install the Claude Desktop App

This course runs in the Claude Desktop app.

1. Go to [claude.ai/download](https://claude.ai/download)
2. **Mac:** download the installer, open it, and drag Claude into your Applications folder
3. **Windows:** download the installer and run it
4. Open the app and sign in with your Claude account

## Open the Code Tab

1. In the Claude app, click the **Code** tab (upper left):

   <img src="/images/code-tab.png" alt="The Code tab — upper left of the Claude Desktop app" width="240" style={{borderRadius:'8px'}} />

2. Start a **new project** - Claude will ask where to keep it; anywhere is fine

The Code tab is full Claude Code with a folder picker and buttons instead of commands. If you can see it, you're installed.
